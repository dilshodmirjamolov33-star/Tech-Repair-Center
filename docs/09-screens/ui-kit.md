# UI Kit — Tech Repair Center

**Версия:** 1.0  
**Забони асосӣ:** тоҷикӣ  
**Манбаи услуб:** `assets/style.css` дар решаи лоиҳа

## 1. Самти визуалӣ

Тарҳ бояд ҳисси эътимоднокӣ, дақиқӣ ва хизматрасонии касбиро расонад. Интерфейс минималистӣ буда, ҳолати таъмир, рақами квитансия ва амалҳои муҳимро дар мадди аввал мегузорад.

## 2. Палитраи рангҳо

Рангҳои зерин аз CSS-и мавҷудаи лоиҳа гирифта шудаанд; барои мутобиқати экранҳои нав онҳоро бе зарурат иваз накунед.

| Токен | Қимат | Истифода |
|---|---|---|
| `--ink` | `#0A2624` | Header, блокҳои асосии торик |
| `--ink2` | `#123B37` | Ҳолати интихобшуда ва сатҳҳои дуюм |
| `--mist` | `#EDF3F0` | Заминаи умумӣ |
| `--card` | `#FFFFFF` | Кортҳо ва сатҳҳои форма |
| `--line` | `#D5E0DB` | Сарҳад ва ҷудокунакҳо |
| `--txt` | `#12302D` | Матни асосӣ |
| `--mut` | `#5F7773` | Матни дуюмдараҷа |
| `--trace` | `#4FD1C5` | Timeline ва таъкиди мусбат |
| `--amber` | `#F2B544` | Тугмаи асосӣ ва огоҳии муҳим |
| `--bad` | `#C43D3D` | Хато ва ҳолати манфӣ |

Барои ҳолатҳои фармоиш рангҳо бо матни ҳолат истифода шаванд. Танҳо ранг барои фаҳмондани маъно кофӣ нест.

## 3. Типография

| Нақш | Шрифт | Андоза |
|---|---|---|
| Сарлавҳаи асосӣ | Unbounded | 26–36 px |
| Сарлавҳаи бахш | Unbounded / Inter | 18–24 px |
| Сарлавҳаи корт | Inter, 600–700 | 16–18 px |
| Матни асосӣ | Inter | 14–16 px |
| Матни ёрирасон | Inter | 12–13 px |
| Рақами квитансия | Unbounded | 18–22 px |

Fallback: `Inter, system-ui, sans-serif`. Агар Unbounded дастрас набошад, аз шрифти системавии sans-serif истифода шавад.

## 4. Фосила ва геометрия

- Системаи фосила: 4, 8, 12, 16, 24, 32 ва 48 px.
- Радиуси корт: 18 px (мутобиқ ба `--r`).
- Радиуси тугма: 12 px.
- Радиуси input: 10 px.
- Баландии input ва тугма: ҳадди ақал 44 px.
- Паҳнои контейнер: тақрибан 1100 px.
- Фосилаи байни блокҳо: 16–24 px.

## 5. Компонентҳои интерфейс

### Тугмаҳо

| Навъ | Истифода |
|---|---|
| Primary | Қабул кардан, сабт кардан, ҷустуҷӯ |
| Secondary / Ghost | Бозгашт, кушодани тафсилот, амали иловагӣ |
| Danger | Рад ё бекоркунӣ — танҳо бо иҷозати мувофиқ |

Матни тугма бояд амали мушаххасро ифода кунад: «Қабул ва квитансия», «Иваз кардани ҳолат», «Иловаи қисм».

### Майдонҳои форма

- Ҳар input label-и доимӣ дошта бошад.
- Placeholder танҳо намуна бошад, на ивазкунандаи label.
- Майдонҳои ҳатмӣ равшан ишора шаванд.
- Хатои санҷиш дар назди майдони дахлдор нишон дода шавад.
- Телефон, рақами квитансия ва IMEI бо формати мувофиқ санҷида шаванд.

### Корт ва ҷадвал

Корти фармоиш рақами квитансия, дастгоҳ, мизоҷ, масъул ва ҳолатро нишон медиҳад. Ҷадвал сарлавҳаи равшан дошта, дар мобилӣ ба scroll-и уфуқӣ ё кортҳои алоҳида табдил ёбад.

### Нишони ҳолат

| Код дар база | Нишон дар UI | Ранги тавсияшаванда |
|---|---|---|
| `received` | Қабул шуд | `#DDEBE7` |
| `diagnosis` | Ташхис | `#FFE8B8` |
| `repair` | Дар таъмир | `#CFE3FF` |
| `ready` | Тайёр | `#C9F2DD` |
| `delivered` | Супорида шуд | `#E3E3E3` |
| Натиҷаи номуваффақ | Хато | `#FFD5D5` |

### Timeline

Timeline барои нишон додани марҳилаҳои таъмир истифода мешавад. Марҳилаи гузашта, ҷорӣ ва оянда бояд аз ҳам фарқ кунанд. Дар ҳар марҳила номи матнӣ намоиш дода шавад.

## 6. Мутобиқшавӣ (Responsive)

| Андоза | Қоида |
|---|---|
| Mobile: то 639 px | Як сутун, менюи ҷамъшаванда, тугмаҳои васеъ |
| Tablet: 640–1023 px | То ду сутун, ҷадвали scrollшаванда |
| Desktop: аз 1024 px | Панели пурра ва ҷадвалҳои васеъ |

## 7. Дастрасӣ (Accessibility)

- Контрасти матн ва замина кофӣ бошад.
- Ҳамаи амалҳо бо клавиатура дастрас бошанд.
- Ҳолати фокус бо `:focus-visible` равшан нишон дода шавад.
- Барои тугмаҳо ва input-ҳо номи фаҳмо истифода шавад.
- Паёмҳои хатогӣ танҳо бо ранг фарқ накунанд.
- Барои аниматсияҳо `prefers-reduced-motion` риоя шавад.

## 8. Қоидаҳои забон ва формат

- Забони асосӣ — тоҷикӣ.
- Формати сана: `DD.MM.YYYY`.
- Воҳиди пул: сомонӣ (`сом.`).
- Рақами квитансия дар тамоми саҳифаҳо яксон нишон дода шавад.
- Истилоҳоти техникӣ танҳо дар ҷое истифода шаванд, ки барои кормандон фаҳмо бошанд.

## 9. Амният ва махфият дар UI

- Саҳифаи оммавии пайгирӣ танҳо маълумоти зарурии фармоишро нишон диҳад.
- Рақами телефон, суроға ва маълумоти шахсӣ дар натиҷаи ҷустуҷӯи оммавӣ ошкор нашавад.
- Маълумоти фармоиш танҳо баъд аз санҷиши иҷозати серверӣ дастрас шавад.
- Амалҳои тағйирдиҳанда бо CSRF муҳофизат карда шаванд.
- Рақами квитансия набояд ягона механизми ҳифзи маълумоти ҳассос бошад; барои маълумоти муфассал бояд авторизатсия талаб карда шавад.

## 10. Принсипи нигоҳдории услуб

Ҳангоми тағйири интерфейс токенҳои ранг ва андоза дар як ҷо нигоҳ дошта шаванд. Барои ҳар саҳифаи нав CSS-и такрорӣ насозед; аввал компонентҳои мавҷударо истифода баред.

11 — Ҳолатҳои ҷустуҷӯ ва коркарди хатогиҳо: Tech Repair Center
Мақсад
Ин ҳуҷҷат рафтори интизоршавандаи интерфейсро ҳангоми ҷустуҷӯи фармоиш, хатогиҳои воридкунии маълумот ва кор бо матни истифодабаранда муайян мекунад. Он бахшҳои 09-screens ва 10-screens-ро пурра мекунад, аммо ҷойгузини супориши техникии асосӣ нест.
1. Ҷустуҷӯ аз рӯи квитансия
Масир: index.php?r={receipt_no}.

Ҳолатҳои интерфейс:
- Idle (интизор): форма рақами квитансияро интизор аст.
- Submitting (фиристодан): форма фиристода шудааст; ҳангоми гузариш ба сервер нишон додани spinner-и алоҳидаи муштарӣ ҳатмӣ нест.
- Found (ёфт шуд): рақами квитансия, модели дастгоҳ, санаи қабул ва ҳолати ҷорӣ нишон дода мешаванд.
- Not found (ёфт нашуд): паёми бетараф нишон дода мешавад, бе ошкор кардани тафсилоти техникии система.
- Unavailable (дастнорас): ҳангоми хатои пайвастшавӣ ё пойгоҳи додаҳо паёми умумӣ нишон дода шавад. Stack trace ва маълумоти пайвастшавӣ набояд намоиш дода шаванд.
2. Формаи қабули дастгоҳ
Масир: order_new.php.

Маълумоте, ки бояд санҷида шавад:
- номи муштарӣ — сатри холӣ набошад ва дарозии иҷозатдошта дошта бошад;
- телефон — рақами ба шакли стандартӣ овардашуда бо формати иҷозатдошта;
- навъи дастгоҳ — танҳо яке аз арзишҳои иҷозатдодаи enum;
- бренд ва модел — сатрҳои холӣ набошанд ва маҳдудияти дарозӣ дошта бошанд;
- навъи нуқсон — танҳо арзиши аз рӯйхати серверӣ интихобшуда;
- тавсифи нуқсон — холӣ набошад ва маҳдудияти дарозӣ дошта бошад;
- муҳлати кафолат — адади бутуни манфӣ набошад ва дар ҳудуди муайяншуда қарор дошта бошад;
- устои таъиншуда — истифодабарандаи мавҷуд ва фаъол бо нақши master бошад.
Атрибутҳои HTML-и required, min ва type барои беҳтар кардани таҷрибаи истифодабаранда муфиданд, аммо санҷиши сервериро иваз намекунанд.
3. Тасдиқи амали хатарнок
Агар функсияи бекор кардани фармоиш илова шавад, пеш аз фиристодани амал бояд равзанаи тасдиқ бо рақами квитансия ва огоҳӣ дар бораи натиҷаи амал нишон дода шавад. Бекоркунӣ бояд амали алоҳида бошад, на танҳо интихоби тасодуфии ҳолат аз рӯйхати dropdown.

Сервер бояд:
1. Аутентификатсия ва нақши истифодабарандаро санҷад.
2. Токени CSRF-ро санҷад.
3. Иҷозат будани гузариш аз ҳолати ҷорӣ ба ҳолати мақсаднокро санҷад.
4. Тағйирот ва сабти таърихро дар як транзаксия иҷро кунад.
5. Натиҷаи равшан баргардонад ва audit trail (таърихи аудиторӣ)-ро нигоҳ дорад.
4. Муҳофизати матни истифодабаранда
Барои матне, ки дар HTML нишон дода мешавад, тавассути helper-и e() функсияи htmlspecialchars(..., ENT_QUOTES, 'UTF-8') истифода шавад. Барои атрибутҳои HTML низ экранидани мувофиқ ба контекст истифода карда шавад. HTML аз сатрҳои боваринок набуда тавассути innerHTML сохта нашавад. Барои SQL дархостҳои омодашуда (prepared statements) истифода шаванд.
5. Меъёрҳои қабул
- Истифодабаранда мефаҳмад, ки чӣ рӯй дод ва хатогиро чӣ гуна ислоҳ кунад.
- Хатогиҳо SQL, паролҳо, роҳҳои мутлақи файлҳо ва stack trace-ро ошкор намекунанд.
- Формаи нодуруст набояд фармоиши қисман сабтшуда эҷод кунад.
- Дархостҳои ҳамзамон ё такрорӣ набояд бе қарори огоҳона фармоишҳои такрорӣ эҷод кунанд.
- Матни HTML/JavaScript ҳамчун матни оддӣ нишон дода шавад, на ҳамчун коде, ки иҷро мешавад.
- Бекор кардани равзанаи тасдиқ набояд маълумотро тағйир диҳад.

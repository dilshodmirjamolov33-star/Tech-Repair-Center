**Мақсади таҳқиқот:** омӯзиши роҳҳалҳои мавҷудаи нармафзорӣ барои автоматикунонии марказҳои хизматрасонӣ ва устохонаҳои таъмири техника, муайян намудани бартарӣ ва маҳдудиятҳои онҳо, асоснок кардани зарурати таҳияи веб-системаи худии Tech Repair Center ва муайян намудани вазифаҳое, ки дар лоиҳа татбиқ кардан мувофиқи мақсад аст.

**Санаи таҳқиқот:** 11.11.2026.

### 1.2. Тавсифи ҷадвали баҳогузорӣ

Барои муқоиса ҷадвали ягонаи седараҷаи баҳогузорӣ истифода мешавад:

- **0** — чунин имконият вуҷуд надорад ё мавҷудияти он бо ҳуҷҷатҳои расмии дастрас тасдиқ нашудааст.
- **1** — имконият қисман амалӣ шудааст, маҳдудият дорад ё модулу танзимоти иловагиро талаб мекунад.
- **2** — имконият дар ҳуҷҷатҳои маҳсулот ба таври возеҳ тавсиф шуда, ба меъёр мувофиқат мекунад.

**K1 — Қабули техника ва бақайдгирии дархост**

- `0` — воситаҳои бақайдгирии муроҷиат ё фармоиши таъмир вуҷуд надоранд.
- `1` — фармоишро танҳо корманд ё тавассути канали маҳдуд сабт карда метавонад.
- `2` — эҷоди дархости таъмир тавассути шакли вебӣ, портал ё интерфейси корӣ дастгирӣ мешавад.

**K2 — Идоракунии фармоишҳо ва марҳилаҳои таъмир**

- `0` — баҳисобгирии фармоишҳои таъмир вуҷуд надорад.
- `1` — рӯйхати одии фармоишҳо мавҷуд аст, вале идоракунии марҳилаҳо маҳдуд мебошад.
- `2` — кортҳои фармоиш, ҳолатҳо, таърихи коркард ва идоракунии раванди таъмир пешбинӣ шудаанд.

**K3 — Ташхис, ҳисоб кардани арзиш ва мувофиқа**

- `0` — воситаҳои сабти натиҷаи ташхис ва баҳодиҳии таъмир вуҷуд надоранд.
- `1` — танҳо қисми имкониятҳо, масалан смета ё қайдҳо, дастрасанд, вале мувофиқаи муштарӣ тасдиқ нашудааст.
- `2` — сабти ташхис, таҳияи арзиши пешакӣ ё смета ва гирифтани қарори муштарӣ оид ба корҳои пешниҳодшуда имконпазир аст.

**K4 — Таъини устоҳо ва банақшагирии корҳо**

- `0` — таъини кормандони масъул пешбинӣ нашудааст.
- `1` — корманди масъулро нишон додан мумкин аст, вале банақшагирии сарборӣ ё ҷадвали кор маҳдуд мебошад.
- `2` — таъини иҷрокунандагон, тақсимоти фармоишҳо ва воситаҳои банақшагирӣ дастрасанд.

**K5 — Баҳисобгирии қисмҳои эҳтиётӣ ва мавод**

- `0` — баҳисобгирии қисмҳо вуҷуд надорад.
- `1` — рӯйхати одии молҳо ё мавод мавҷуд аст, вале он бо фармоишҳои таъмир алоқаманд нест.
- `2` — баҳисобгирии анборӣ, назорати бақия ва робитаи қисмҳо бо фармоишҳо ё амалиётҳои таъмир амалӣ шудааст.

**K6 — Утоқи шахсии муштарӣ, таърих ва огоҳиномаҳо**

- `0` — муштарӣ тавассути система дар бораи фармоишҳои худ маълумот гирифта наметавонад.
- `1` — баъзе имкониятҳои огоҳсозӣ ё дидани маълумот мавҷуданд, вале утоқи пурраи муштарӣ ва таърихи он тасдиқ нашудааст.
- `2` — муштарӣ метавонад фармоишҳо ё таърихи онҳоро бинад, паём гирад ва тавассути портал бо маркази хизматрасонӣ ҳамкорӣ кунад.

**K7 — Баҳисобгирии пардохтҳо ва таҳияи ҳисобномаҳо**

- `0` — баҳисобгирии пардохтҳо ва ҳисобномаҳо вуҷуд надорад.
- `1` — танҳо як қисми вазифаҳои молиявӣ, масалан сабти дастии пардохт ё таҳияи смета, дастрас аст.
- `2` — ҳисобномаҳо, сабти пардохтҳо ва ҳамгироӣ бо воситаҳои пардохт ё амалиётҳои хазинавӣ мавҷуданд.

**K8 — Дастрасӣ аз дастгоҳҳои мобилӣ**

- `0` — истифода аз дастгоҳҳои мобилӣ амалан пешбинӣ нашудааст.
- `1` — дастрасии вебӣ имконпазир аст, вале имкониятҳои пурраи мобилӣ ё қулайии интерфейс тасдиқ нашудаанд.
- `2` — истеҳсолкунанда дастрасии мобилӣ, барномаи мобилӣ ё воситаҳои мутобиқшуда барои кор берун аз компютерро ба таври возеҳ нишон медиҳад.

**K9 — Мутобиқсозии забонӣ ва усулҳои маҳаллии пардохт**

- `0` — дастгирии ҳамзамони забонҳои русӣ ва тоҷикӣ ва роҳҳалҳои пардохтии Тоҷикистон тасдиқ нашудааст.
- `1` — танҳо қисми талабот тасдиқ шудааст, масалан як забони алоҳида ё имконияти танзими асъор.
- `2` — забонҳои русӣ ва тоҷикӣ ва ҳамгироӣ бо роҳҳалҳои пардохтии дар Тоҷикистон истифодашаванда тасдиқ шудаанд.

**K10 — Ҳисобот, таҳлил ва назорати амалҳо**

- `0` — воситаҳои таҳлилӣ вуҷуд надоранд.
- `1` — ҷамъбасти одӣ ё ҳисоботҳои маҳдуд дастрасанд.
- `2` — ҳисоботҳо оид ба фармоишҳо, кормандон, захираҳо, даромад ё амалҳои истифодабарандагон мавҷуданд.

**Эзоҳ:** баҳодиҳии `0` аз рӯи меъёри K9 маънои онро дорад, ки мутобиқат ба талаботи маҳз Тоҷикистон тасдиқ нашудааст, на ин ки система умуман имконияти маҳаллисозӣ надорад. Баҳогузорӣ ба тавсиф ва ҳуҷҷатҳои дастраси таҳиягарон асос ёфтааст, на ба санҷиши ҳисобҳои пулакӣ. Пеш аз татбиқи маҳсулоти тиҷоратӣ бояд имкониятҳо ва маҳдудиятҳои тарофавии он алоҳида санҷида шаванд.

### 2.2. Хусусиятҳо ва маҳдудиятҳои ҳар як системаи ҳаммонанд

**1. RepairDesk ([М1])**

RepairDesk — нармафзори абрӣ барои марказҳои хизматрасонӣ ва устохонаҳои таъмир мебошад. Маҳсулот, аз ҷумла, ба таъмири телефонҳои мобилӣ, компютерҳо, электроника ва дигар намудҳои техника равона шудааст.

Имкониятҳои тасдиқшуда:

- Бақайдгирӣ ва идоракунии дархостҳои таъмир (Repair Ticket Management).
- Бақайдгирии мустақилонаи муштарӣ тавассути Self Check-In.
- Идоракунии кормандон ва амалҳои онҳо.
- Баҳисобгирии қисмҳои эҳтиётӣ ва бақияи анбор.
- Огоҳиномаҳо ҳангоми кам шудани миқдори қисмҳо дар анбор.
- Пардохти онлайн барои хизматрасониҳои таъмир.
- Ҳисобот оид ба фаъолияти устохонаи таъмир.
- Ҳамгироӣ бо хизматрасониҳои вебии беруна.
- Намоишгари муштарӣ ва тасдиқи рақамии шартҳои хизматрасонӣ.

Маҳдудиятҳо:

- Маҳсулот барои истифодаи тиҷоратӣ пешбинӣ шуда, ҳамчун нармафзори махсусгардонидашуда пешниҳод мегардад.
- Дастгирии пурраи забони тоҷикӣ ва ҳамгироӣ бо хизматрасониҳои пардохтии маҳаллӣ тасдиқ нашудааст.
- Имконияти мустақилона ҷойгир кардани тамоми система дар сервери маҳаллӣ тасдиқ нашудааст.
- Қисме аз имкониятҳо ва ҳамгириҳо метавонанд аз тарофа ва хизматрасониҳои беруна вобаста бошанд.

Манбаъ: саҳифаи расмии имкониятҳои RepairDesk — [https://www.repairdesk.co/Features/](https://www.repairdesk.co/Features/).

**2. RepairShopr ([М2])**

RepairShopr — системаи идоракунии тиҷорати таъмир буда, CRM, баҳисобгирии дархостҳо, сметаҳо, ҳисобномаҳо, пардохтҳо ва баҳисобгирии анборро муттаҳид мекунад.

Имкониятҳои тасдиқшуда:

- Идоракунии муштариён ва маълумоти тамосии онҳо.
- Бақайдгирӣ ва пайгирии дархостҳои таъмир (Tickets).
- Филтр кардани фармоишҳо аз рӯи ҳолат ва мутахассиси таъиншуда.
- Сабти пешрафти таъмир ва шарҳҳои дохилӣ.
- Таҳияи смета ва фиристодани он ба муштарӣ барои тасдиқ ё радкунӣ.
- Портали вебии муштарӣ барои дидани дархостҳо ва таърихи онҳо.
- Дидани ҳисобномаҳо ва пардохт тавассути ҳамгириҳои дастрас.
- Баҳисобгирии қисмҳои эҳтиётӣ, бақия ва фармоишҳо ба таъминкунандагон.
- Огоҳинома тавассути почтаи электронӣ ва SMS.
- Ҳисобот оид ба фурӯш, захираҳо, муштариён ва дархостҳо.

Маҳдудиятҳо:

- Маҳсулот ба модели истифодаи тиҷоратӣ равона шудааст.
- Баъзе имкониятҳо аз ҳамгириҳои пайвастшуда ва тарофаи интихобшуда вобастаанд.
- Дастгирии забони тоҷикӣ ва хизматрасониҳои пардохтии маҳаллӣ тасдиқ нашудааст.
- Ҷойгиркунии мустақилонаи коди ибтидоӣ дар сервери худӣ сенарияи стандартии истифодаи маҳсулот нест.

Манбаъҳо: [саҳифаи имкониятҳои RepairShopr](https://www.repairshopr.com/features/) ва [ҳуҷҷатҳои портали муштарӣ](https://repair.uservoice.com/knowledgebase/articles/1942078-customer-portal).

**3. Orderry ([М3])**

Orderry — платформаи абрӣ барои автоматикунонии ширкатҳои хизматрасонӣ, устохонаҳои таъмир ва ташкилотҳои пешниҳодкунандаи хизматрасонӣ мебошад. Система идоракунии фармоишҳо, муштариён, захираҳо, кормандон ва молияро муттаҳид мекунад.

Имкониятҳои тасдиқшуда:

- Эҷоди фармоишҳои корӣ бо маълумоти муштарӣ, дастгоҳ ва нуқсон.
- Нигоҳ доштани таърихи хизматрасониҳои иҷрошуда, маводи истифодашуда ва пардохтҳо.
- Таҳияи арзёбии пешакии арзиши корҳо.
- Табдил додани арзёбии мувофиқашуда ба фармоиши корӣ.
- Банақшагирии корҳо барои рӯзҳо ва ҳафтаҳои муайян.
- Баҳисобгирии захираҳо ва ҳаракати мол дар анбор.
- Идоракунии ҳуқуқи дастрасии кормандон.
- Дафтари сабти амалҳои кормандон.
- Воситаҳои мобилӣ барои кор бо фармоишҳо.
- Ҳисобот оид ба фармоишҳо, захираҳо, кормандон ва нишондиҳандаҳои молиявӣ.

Маҳдудиятҳо:

- Платформа маҳсулоти тиҷоратии абрӣ мебошад.
- Барои истифодаи баъзе имкониятҳо танзими тарофа ё ҳамгироиҳои иловагӣ лозим шуда метавонад.
- Дастгирии пурраи забони тоҷикӣ ва низомҳои пардохтии маҳаллӣ тасдиқ нашудааст.
- Имконияти мустақилона ҷойгир кардани маҳсулот дар сервери маҳаллӣ тасдиқ нашудааст.

Манбаъҳо: [имкониятҳои расмии Orderry](https://orderry.com/features/) ва [тавсифи фармоишҳои корӣ](https://help.orderry.com/en/articles/9133862-work-orders-general-information).

**4. Fixably ([М4])**

## 4. Ҳисобҳои ниҳоӣ ва натиҷаҳо

Барои ба даст овардани натиҷаи муқоисавӣ ба ҳар як меъёр коэффисиенти вазнӣ дода мешавад. Баҳои системаи ҳаммонанд ба вазни меъёр зарб карда шуда, сипас натиҷаҳо ҷамъ карда мешаванд.

### 4.1. Формулаҳои ҳисоб

Ишораҳо:

- `S` — холи ниҳоии вазндори системаи ҳаммонанд.
- `Kᵢ` — баҳои система аз рӯи меъёри дахлдор.
- `Wᵢ` — вазни меъёри дахлдор.
- `Smax` — холи ҳадди аксари имконпазир.

Формулаи холи ниҳоӣ:

\[
S=\sum_{i=1}^{n}(K_i \times W_i)
\]

Холи ҳадди аксар:

\[
S_{max}=2\times\sum_{i=1}^{n}W_i
\]

Фоизи мутобиқат:

\[
P=\frac{S}{S_{max}}\times100\%
\]

Дар ҳолати баррасишаванда:

\[
S_{max}=2\times25=50
\]

### 4.2. Ҳисоби муфассали ҳар як системаи ҳаммонанд

**1. RepairDesk**

\[
S=2(2)+3(2)+3(1)+2(2)+3(2)+3(1)+2(2)+2(2)+3(0)+2(2)
\]

\[
S=4+6+3+4+6+3+4+4+0+4=38
\]

\[
P=\frac{38}{50}\times100\%=76\%
\]

**2. RepairShopr**

\[
S=4+6+6+4+6+6+4+4+0+4=44
\]

\[
P=\frac{44}{50}\times100\%=88\%
\]

**3. Orderry**

\[
S=4+6+6+4+6+3+4+4+0+4=41
\]

\[
P=\frac{41}{50}\times100\%=82\%
\]

**4. Fixably**

\[
S=4+6+3+4+6+6+4+4+0+4=41
\]

\[
P=\frac{41}{50}\times100\%=82\%
\]

**5. Odoo Repairs**

\[
S=2+6+6+4+6+3+4+2+0+4=37
\]

\[
P=\frac{37}{50}\times100\%=74\%
\]

Сабаби он муттаҳид шудани баҳисобгирии дархостҳои таъмир, портали муштарӣ, мувофиқаи сметаҳо, инвентаризатсия ва вазифаҳои молиявӣ мебошад. ## 6. Асосноккунии таҳияи системаи худии Tech Repair Center

Таҳияи веб-системаи худии Tech Repair Center бо зарурати сохтани роҳҳали дастрас ва мутобиқшуда барои маркази хизматрасоние, ки дар шароити Тоҷикистон фаъолият мекунад, асоснок карда мешавад.

Бар хилофи платформаҳои тиҷоратии универсалӣ, системаи таҳияшаванда ба равандҳои мушаххаси як маркази таъмири техника равона шуда, имкон медиҳад, ки функсионалӣ тадриҷан васеъ карда шавад ва зарурати харидани системаи мураккаби корпоративӣ ба миён наояд.

### 6.1. Хусусиятҳои функсионалии системаи таҳияшаванда

Дар лоиҳа татбиқи имкониятҳои зерин пешбинӣ мешавад:

1. **Феҳристи хизматрасониҳо:** намоиши намудҳои таъмир, тавсифи хизматрасониҳо ва арзиши тахминӣ.
2. **Бақайдгирии муштариён:** эҷоди ҳисоб ва воридшавӣ ба утоқи шахсӣ.
3. **Дархости онлайн:** фиристодани муроҷиат бо нишон додани навъи техника, модел ва тавсифи нуқсон.
4. **Корти дастгоҳ:** нигоҳ доштани маълумот дар бораи истеҳсолкунанда, модел, рақами силсилавӣ ва ҳолати дастгоҳ.
5. **Идоракунии фармоишҳо:** бақайдгирӣ, ҷустуҷӯ, таҳрир ва дидани дархостҳои таъмир.
6. **Ташхис:** сабти натиҷаи санҷиши дастгоҳ, нуқсонҳои ошкоршуда ва тавсияҳои усто.
7. **Мувофиқаи арзиш:** нигоҳ доштани сметаи пешакӣ ва қарори муштарӣ оид ба иҷрои таъмир.
8. **Таъини устоҳо:** тақсим кардани фармоишҳо байни кормандон ва дидани вазифаҳои таъиншуда.
9. **Назорати ҳолатҳо:** намоиши марҳилаи ҷории таъмир дар утоқи шахсии муштарӣ.
10. **Баҳисобгирии қисмҳои эҳтиётӣ:** бақайдгирии қисмҳо, назорати миқдор ва сабти истифодаи онҳо дар фармоиш.
11. **Пардохт:** нигоҳ доштани маблағи таъмир, усули пардохт ва ҳолати ҳисоббаробаркунӣ.
12. **Таърихи хизматрасонӣ:** нигоҳ доштани маълумот дар бораи таъмирҳои пешина ва корҳои иҷрошуда.
13. **Огоҳиномаҳо:** огоҳ кардани муштарӣ дар бораи эҷоди дархост, натиҷаи ташхис ва омода шудани дастгоҳ.
14. **Панели маъмурӣ:** идоракунии истифодабарандагон, кормандон, хизматрасониҳо, фармоишҳо ва омор.

### 6.2. Хусусиятҳои маҳаллӣ

Ҳангоми тарҳрезии Tech Repair Center имкониятҳои зерин пешбинӣ мешаванд:

- Интерфейс бо забонҳои русӣ ва тоҷикӣ.
- Истифодаи сомонӣ (TJS) ҳамчун асъори асосӣ барои нишон додани арзиш.
- Имконияти сабти дастии пардохти нақдӣ ва ғайринақдӣ.
- Имконияти пайваст кардани хизматрасониҳои пардохтии маҳаллӣ дар оянда, пас аз санҷидани шартҳои техникии онҳо.
- Таҳияи интерфейси мутобиқшаванда барои смартфон, планшет ва компютер.
- Имконияти ба таври маҳаллӣ ба кор андохтани лоиҳа бо истифодаи PHP, MySQL ва Apache тавассути XAMPP.

**Муҳим:** дар марҳилаи аввал ҳамгироӣ бо хизматрасониҳои мушаххаси пардохтӣ вазифаи аллакай татбиқшуда ҳисобида намешавад. Аввал система бояд сабти дурусти пардохтҳоро таъмин кунад. Пардохти онлайн метавонад баъд аз гирифтани дастрасии зарурӣ ба API ва санҷидани талаботи провайдери пардохт илова карда шавад.

## Хулоса

Дар рафти таҳлили муқоисавӣ панҷ роҳҳали нармафзорӣ барои автоматикунонии фаъолияти устохонаҳои таъмир ва марказҳои хизматрасонӣ баррасӣ гардиданд: RepairDesk, RepairShopr, Orderry, Fixably ва Odoo Repairs.

Таҳқиқот нишон дод, ки системаҳои муосир метавонанд марҳилаҳои асосии фаъолияти маркази хизматрасониро автоматикунонӣ кунанд: бақайдгирии дархостҳо, идоракунии фармоишҳо, ташхис, тақсим кардани корҳо байни кормандон, баҳисобгирии қисмҳои эҳтиётӣ, ҳисоббаробаркунӣ бо муштариён ва таҳияи ҳисобот.

Аз рӯи маҷмӯи меъёрҳои интихобшуда натиҷаи баландтаринро RepairShopr — 88% ба даст овард. Бо вуҷуди ин, ҳеҷ яке аз системаҳои ҳаммонанди баррасишуда мутобиқат ба ҳамаи талаботи маҳаллисозӣ барои Тоҷикистонро тасдиқ накард. Ин ҳолат муҳиммияти таҳияи системаи худии Tech Repair Center-ро нишон медиҳад.

Системаи пешниҳодшуда бо истифода аз PHP ва MySQL, инчунин HTML, CSS ва JavaScript амалӣ карда мешавад. Вазифаи асосии он фароҳам овардани роҳи қулай барои фиристодан ва пайгирии дархостҳо барои муштариён ва воситаҳои самараноки идоракунии равандҳои таъмир барои кормандону маъмурият мебошад.

Натиҷаҳои таҳлили муқоисавӣ ҳангоми таҳияи супориши техникӣ, лоиҳакашии диаграммаҳои UML, таҳияи сохтори пойгоҳи додаҳо ва муайян намудани талаботи функсионалӣ ба веб-барнома истифода мешаванд.

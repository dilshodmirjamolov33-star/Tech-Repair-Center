# 07 — Диаграммаи ҷойгиркунии веблоиҳаи маркази таъмири техника

## Мақсад

Диаграмма ҷойгиршавии физикии пешниҳодшудаи ҷузъҳои веблоиҳаи маркази таъмири техникаро нишон медиҳад. Дар он робитаи браузери истифодабаранда бо сервери барнома, пойгоҳи додаҳо, анбори файлҳо ва хизматрасониҳои беруна тасвир карда мешавад.

## Гиреҳҳои ҷойгиркунӣ

1. **Дастгоҳи истифодабаранда** — компютер, ноутбук, планшет ё смартфон, ки тавассути браузери веб ба система ворид мешавад. Дар браузер интерфейси веблоиҳаи маркази таъмири техника намоиш дода мешавад.

2. **Интернет** — воситаи интиқоли дархостҳо ва ҷавобҳо байни дастгоҳи истифодабаранда ва сервери барнома.

3. **Сервери барнома** — қисми асосии веблоиҳа, ки интерфейси серверӣ, API (агар дар татбиқ истифода шавад), воридшавӣ ба система ва санҷиши ҳуқуқи истифодабарандагонро таъмин мекунад. Ин сервер дархостҳои сабти муштарӣ, бақайдгирии дастгоҳ, қабули фармоиши таъмир, ташхиси нуқсон, тағйир додани ҳолати фармоиш, ҳисоббаробаркунӣ ва фиристодани огоҳиномаҳоро коркард менамояд.

4. **Сервери пойгоҳи додаҳо** — пойгоҳи додаҳои релятсионии маркази таъмири техника. Дар он маълумоти истифодабарандагон, хизматрасониҳо, дастгоҳҳо, фармоишҳои таъмир, ташхисҳо, таърихи ҳолати фармоишҳо, қисмҳои эҳтиётӣ, қисмҳои истифодашуда дар фармоишҳо, пардохтҳо, огоҳиномаҳо ва баррасиҳо нигоҳ дошта мешаванд. Ҷадвалҳои асосӣ:
   - `users`
   - `services`
   - `devices`
   - `repair_orders`
   - `diagnoses`
   - `order_status_history`
   - `parts`
   - `order_parts`
   - `payments`
   - `notifications`
   - `reviews`

5. **Сервери анбори файлҳо** — барои нигоҳ доштани аксҳои дастгоҳҳо, тасвирҳои нуқсонҳо, аксҳои раванди таъмир, ҳуҷҷатҳо ва дигар файлҳои ба фармоишҳои таъмир алоқаманд истифода мешавад. Файлҳо метавонанд дар сервери алоҳида ё дар анбори файлҳои муҳити ҷойгиркунӣ нигоҳ дошта шаванд.

6. **Хизматрасониҳои беруна** — хизматрасонии пардохт (агар пардохти онлайн дар система татбиқ шавад) ва провайдерҳои Email / SMS барои фиристодани огоҳиномаҳо ба муштариён ё кормандони марказ.

## Қоидаҳои муҳими меъморӣ

- Мубодилаи маълумот байни браузери истифодабаранда ва сервери барнома бояд тавассути HTTPS анҷом дода шавад.
- Воридшавӣ ба система, санҷиши шахсияти истифодабаранда, муайян кардани нақш ва санҷиши ҳуқуқи дастрасӣ дар тарафи сервер иҷро карда мешаванд.
- Истифодабаранда танҳо ба маълумот ва амалҳое дастрасӣ дорад, ки ба нақш ва ҳуқуқҳои ӯ мувофиқанд.
- Ҳангоми сабти фармоиши таъмир сервер бояд дурустии маълумоти муштарӣ ва дастгоҳи ба фармоиш вобасташударо санҷад.
- Тағйир додани ҳолати фармоиш бояд дар сервер коркард шуда, таърихи тағйирот дар ҷадвали `order_status_history` нигоҳ дошта шавад.
- Маълумоти пардохт аз ҳолати фармоиши таъмир ҷудо нигоҳ дошта мешавад; ҳолати пардохт ва ҳолати фармоиш набояд ҳамчун як маълумот истифода шаванд.
- Амалиётҳои вобаста ба фармоиш, қисмҳои эҳтиётӣ ва пардохтҳо ҳангоми зарурат бояд бо истифода аз транзаксияҳои пойгоҳи додаҳо иҷро шаванд, то маълумот номувофиқ нашавад.
- Хизматрасониҳои пардохт ва ирсоли паёмҳо ҳамчун вобастагиҳои алоҳидаи беруна баррасӣ мешаванд. Агар чунин хизматрасониҳо дар версияи амалии лоиҳа истифода нашаванд, онҳо метавонанд дар марҳилаи татбиқ хориҷ карда шаванд.

## Файли диаграмма

- `07-deployment.puml` — файли дорои рамзи ибтидоии диаграммаи ҷойгиркунӣ дар PlantUML.

## Эзоҳ оид ба татбиқ

Ин диаграмма топологияи мантиқии пешниҳодшудаи ҷойгиркунии веблоиҳаи маркази таъмири техникаро нишон медиҳад ва ба модели мантиқии пойгоҳи додаҳои лоиҳа такя мекунад. Технологияҳои мушаххас, суроғаҳои гиреҳҳо, контейнерҳо, портҳо, системаи амалиётӣ, провайдери абрӣ ва тарзи тақсимоти шабака бояд мувофиқи конфигуратсияи воқеии лоиҳа ва муҳити истифодабарӣ муайян карда шаванд.

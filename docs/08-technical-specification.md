# 08 — Талаботи техникӣ барои таҳияи веблоиҳаи маркази таъмири техника

**Номи лоиҳа:** Веблоиҳаи маркази таъмири техника (Tech Repair Center)  
**Мавзӯи лоиҳа:** «Коркарди веблоиҳаи маркази таъмири техника»  
**Технологияҳои интихобшуда:** PHP, MySQL, HTML, CSS, JavaScript  
**Муҳити таҳия:** Visual Studio Code (VS Code)

---

## 1. Муқаррароти умумӣ

### 1.1. Номи система

Системаи иттилоотии вебии «Маркази таъмири техника» (минбаъд — Система).

### 1.2. Асос барои таҳия

Система дар доираи лоиҳаи таълимӣ бо мақсади автоматӣ намудани қабули дастгоҳҳо барои таъмир, бақайдгирии муштариён, идоракунии фармоишҳои таъмир ва назорати ҳолати иҷрои онҳо таҳия карда мешавад.

### 1.3. Мақсади асосӣ

Мақсади лоиҳа сохтани веб-барномаи дастрас ва қулай мебошад, ки фаъолияти ҳаррӯзаи маркази таъмири техника ва мубодилаи маълумотро байни муштарӣ, усто ва маъмур осон мекунад.

### 1.4. Соҳаи истифода

Система барои марказҳое пешбинӣ шудааст, ки хизматрасонии ташхис ва таъмири ноутбук, компютер, смартфон ва дигар таҷҳизоти техникиро пешниҳод мекунанд. Рӯйхати дақиқи намудҳои техника ва хизматрасониҳо аз ҷониби маъмури система идора карда мешавад.

### 1.5. Истилоҳот ва ихтисорот

| Истилоҳ | Маъно |
|---|---|
| Система | Веблоиҳаи маркази таъмири техника |
| Муштарӣ | Шахсе, ки дастгоҳро барои таъмир месупорад |
| Усто | Мутахассисе, ки ташхис ва таъмири дастгоҳро иҷро мекунад |
| Маъмур | Истифодабарандае, ки система ва маълумоти онро идора мекунад |
| Фармоиш | Сабти дархост ва раванди таъмири дастгоҳ |
| Ташхис | Муайян кардани нуқсон ва сабаби вайроншавии дастгоҳ |
| PK | Калиди ибтидоии ҷадвал |
| FK | Калиди хориҷии ҷадвал |
| DB | Пойгоҳи додаҳо |

## 2. Тавсифи объект ва равандҳои автоматишаванда

### 2.1. Равандҳои асосӣ

Система бояд равандҳои зеринро дастгирӣ кунад:

1. Бақайдгирӣ ва воридшавии истифодабарандагон.
2. Идоракунии маълумоти муштариён ва кормандон.
3. Илова ва таҳрири феҳристи хизматрасониҳо.
4. Сабти маълумоти дастгоҳи муштарӣ.
5. Қабул ва бақайдгирии фармоиши таъмир.
6. Таъини устои масъул ба фармоиш.
7. Сабти натиҷаи ташхис, нуқсон ва тавсияи таъмир.
8. Тағйир додани ҳолати фармоиш ва нигоҳ доштани таърихи он.
9. Бақайдгирии қисмҳои эҳтиётӣ ва миқдори истифодашуда.
10. Сабти маблағ ва ҳолати пардохт.
11. Огоҳ намудани истифодабаранда дар бораи тағйири ҳолати фармоиш.
12. Сабти баҳогузорӣ ва фикру мулоҳизаи муштарӣ.

### 2.2. Истифодабарандагони система

| Нақш | Имкониятҳои асосӣ |
|---|---|
| Муштарӣ | Бақайдгирӣ, воридшавӣ, иловаи дастгоҳ, фиристодани дархост, дидани фармоишҳои худ, пайгирии ҳолат, дидани пардохт ва гузоштани фикру мулоҳиза |
| Усто | Дидани фармоишҳои ба ӯ таъиншуда, гузаронидани ташхис, иловаи тавсияҳо, навсозии ҳолати таъмир ва сабти қисмҳои истифодашуда |
| Маъмур | Идоракунии истифодабарандагон, хизматрасониҳо, дастгоҳҳо, ҳамаи фармоишҳо, таъини устоҳо, қисмҳои эҳтиётӣ, пардохтҳо ва ҳисобот |

Маъмур ва усто бояд танҳо бо иҷозати мувофиқ ба амалҳои худ дастрасӣ дошта бошанд. Муштарӣ набояд маълумоти фармоишҳои муштариёни дигарро бинад.

### 3.1. Қоидаҳои ҳолати фармоиш

Ҳолатҳои пешниҳодшуда:

- `NEW` — дархости нав;
- `ACCEPTED` — қабул шудааст;
- `DIAGNOSTICS` — ташхис идома дорад;
- `WAITING_APPROVAL` — интизори розигии муштарӣ;
- `APPROVED` — таъмир тасдиқ шудааст;
- `IN_PROGRESS` — таъмир иҷро мешавад;
- `WAITING_PARTS` — интизори қисмҳои эҳтиётӣ;
- `COMPLETED` — таъмир анҷом ёфтааст;
- `ISSUED` — дастгоҳ ба муштарӣ супорида шудааст;
- `REJECTED` — дархост рад шудааст;
- `CANCELLED` — фармоиш бекор шудааст.

Гузариш байни ҳолатҳо бояд аз тарафи сервер санҷида шавад. Ҳар тағйирот бояд дар ҷадвали таърихи ҳолати фармоиш сабт гардад. Ҳолати пардохт аз ҳолати фармоиш ҷудо мебошад.

## 5. Талабот ба интерфейс

### 5.1. Интерфейси муштарӣ

Саҳифаҳои асосӣ:

- Саҳифаи асосӣ ва маълумот дар бораи марказ.
- Рӯйхати хизматрасониҳо.
- Бақайдгирӣ ва воридшавӣ.
- Кабинети шахсии муштарӣ.
- Илова ва рӯйхати дастгоҳҳо.
- Шакли фиристодани дархости таъмир.
- Рӯйхати фармоишҳои шахсӣ.
- Саҳифаи тафсилоти фармоиш ва таърихи ҳолат.
- Маълумоти пардохт.
- Шакли баҳогузорӣ ва фикру мулоҳиза.

### 5.2. Интерфейси усто

- Кабинети усто.
- Рӯйхати фармоишҳои таъиншуда.
- Маълумоти дастгоҳ ва муштарӣ.
- Шакли ташхис.
- Сабти корҳои иҷрошуда ва қисмҳои истифодашуда.
- Навсозии ҳолати фармоиш.

### 5.3. Интерфейси маъмур

- Панели идоракунӣ.
- Идоракунии истифодабарандагон ва нақшҳо.
- Идоракунии хизматрасониҳо.
- Идоракунии дастгоҳҳо ва фармоишҳо.
- Таъини усто ба фармоиш.
- Идоракунии қисмҳои эҳтиётӣ.
- Назорати пардохтҳо.
- Дидани фикру мулоҳизаҳо ва ҳисоботи умумӣ.

### 5.4. Талаботи умумӣ ба интерфейс

Ҳамаи шаклҳо бояд нишонаҳои майдонҳои ҳатмӣ, санҷиши маълумот ва паёмҳои хатогӣ дошта бошанд. Пас аз амалиёти муваффақ система бояд паёми тасдиқ нишон диҳад. Амалҳои хатарнок, аз ҷумла бекоркунӣ ё ғайрифаъолкунӣ, бояд бо тасдиқи иловагӣ иҷро шаванд.

## 6. Талабот ба пойгоҳи додаҳо

### 6.1. Системаи идоракунии пойгоҳи додаҳо

Барои нигоҳдорӣ ва коркарди маълумот MySQL истифода мешавад. Муҳаррики ҷадвалҳо InnoDB интихоб карда мешавад, зеро он калидҳои хориҷӣ ва транзаксияҳоро дастгирӣ мекунад.

### 6.2. Ҷадвалҳои асосӣ

| № | Номи ҷадвал | Таъинот |
|---:|---|---|
| 1 | `users` | Ҳисобҳои муштариён, устоҳо ва маъмурон |
| 2 | `services` | Феҳристи хизматрасониҳо |
| 3 | `devices` | Дастгоҳҳои муштариён |
| 4 | `repair_orders` | Фармоишҳои таъмир |
| 5 | `diagnoses` | Натиҷаҳои ташхис |
| 6 | `order_status_history` | Таърихи тағйири ҳолати фармоиш |
| 7 | `parts` | Феҳристи қисмҳои эҳтиётӣ |
| 8 | `order_parts` | Қисмҳои истифодашуда дар фармоиш |
| 9 | `payments` | Пардохтҳо |
| 10 | `notifications` | Огоҳиномаҳо |
| 11 | `reviews` | Баҳогузорӣ ва фикру мулоҳиза |

### 6.3. Қоидаҳои пойгоҳи додаҳо

- Барои ҳар ҷадвал калиди ибтидоии ягона муайян карда шавад.
- Калидҳои хориҷӣ барои робитаҳои байни ҷадвалҳо истифода шаванд.
- Почтаи электронии ҳисобҳо ва рақами фармоиш такрорнашаванда бошанд.
- Маблағҳо бо навъи `DECIMAL` нигоҳ дошта шаванд.
- Рамзҳои истифодабарандагон дар шакли матни кушода нигоҳ дошта нашаванд.
- Барои ҷадвалҳои дорои маълумоти зиёд индексҳои мувофиқ сохта шаванд.
- Амалиёти сабти фармоиш, қисмҳо ва пардохтҳо ҳангоми зарурат дар транзаксия иҷро шаванд.
- Барои пешгирии гум шудани таърихи молиявӣ фармоишҳо ва пардохтҳо бе асоси маъмурӣ ҳазф карда нашаванд.

## 8. Талаботи амниятӣ

1. Рамзҳои истифодабарандагон бо `password_hash()` ҳеш карда шуда, бо `password_verify()` санҷида шаванд.
2. Барои идоракунии сессия танзимоти бехатар истифода шаванд ва баъд аз воридшавӣ идентификатори сессия нав карда шавад.
3. Ҳуқуқи истифодабаранда дар ҳар амалиёти серверӣ санҷида шавад; пинҳон кардани тугма дар интерфейс кофӣ нест.
4. Муштарӣ танҳо дастгоҳҳо ва фармоишҳои ба ҳисоби худ тааллуқдоштаро дастрас карда тавонад.
5. Усто танҳо фармоишҳои ба ӯ таъиншударо идора карда тавонад, агар маъмур ҳуқуқи васеъ надода бошад.
6. Барои дархостҳои пойгоҳи додаҳо PDO ё MySQLi бо prepared statements истифода шавад.
7. Барои ҳамаи шаклҳои тағйирдиҳандаи маълумот токени CSRF санҷида шавад.
8. Маълумоти воридшаванда дар сервер санҷида шавад; барои баромади HTML `htmlspecialchars()` истифода шавад.
9. Файлҳои боршаванда аз рӯи навъ, андоза ва номи файл санҷида шаванд. Файлҳо набояд ҳамчун скрипт иҷро шаванд.
10. Маълумоти махфӣ, аз ҷумла рамзҳои пойгоҳи додаҳо, дар репозиторияи оммавии GitHub ҷойгир карда нашавад.
11. Дар муҳити воқеӣ HTTPS истифода шавад.
12. Амалиётҳои муҳим, аз ҷумла таъини усто, тағйири ҳолати фармоиш ва сабти пардохт, дар журнал сабт карда шаванд.

## 9. Талабот ба санҷиш ва қабул

### 9.1. Намудҳои санҷиш

- Санҷиши функсионалӣ — дуруст иҷро шудани вазифаҳои система.
- Санҷиши шаклҳо — дурустии маълумоти воридшаванда ва паёмҳои хатогӣ.
- Санҷиши иҷозат — маҳдуд будани дастрасӣ аз рӯи нақш.
- Санҷиши пойгоҳи додаҳо — дурустии робитаҳо ва якпорчагии маълумот.
- Санҷиши интерфейс — намоиши дуруст дар андозаҳои гуногуни экран.
- Санҷиши амният — санҷиши воридшавӣ, иҷозатҳо, CSRF ва SQL Injection.
- Санҷиши раванд — иҷрои пурраи давраи фармоиш аз дархости муштарӣ то супоридани дастгоҳ.

### 9.2. Сенарияҳои асосии санҷиш

| № | Сенария | Натиҷаи интизоршаванда |

| 6 | Маъмур усторо таъин мекунад | Устои интихобшуда ба фармоиш пайваст мешавад |

### 9.3. Меъёрҳои қабул

Система барои қабули ниҳоӣ омода ҳисобида мешавад, агар:

- вазифаҳои асосии дар қисми талаботи функсионалӣ овардашуда иҷро шаванд;
- се нақши асосӣ бо ҳуқуқҳои ҷудогона кор кунанд;
- маълумоти фармоиш, ташхис, қисмҳо ва пардохт дуруст нигоҳ дошта шавад;
- таърихи ҳолати фармоиш дастрас бошад;
- санҷишҳои асосии амниятӣ гузаранд;
- хатогиҳои ҷиддии манъкунандаи истифода бартараф карда шаванд;
- нусхаи сохтори пойгоҳи додаҳо ва дастури оғоз намудани лоиҳа омода бошанд.

## 10. Натиҷаҳои интизоршаванда

Дар натиҷаи иҷрои лоиҳа бояд маҳсулоти зерин омода карда шаванд:

1. Веб-интерфейси маркази таъмири техника.
2. Системаи бақайдгирӣ ва воридшавии истифодабарандагон.
3. Кабинети муштарӣ, усто ва маъмур.
4. Модули сабти дастгоҳ ва фармоиши таъмир.

6. Модули қисмҳои эҳтиётӣ ва пардохтҳо.
7. Модули огоҳинома ва фикру мулоҳиза.
8. Пойгоҳи додаҳои MySQL бо робитаҳо ва маҳдудиятҳои зарурӣ.
9. Файли SQL барои сохтани пойгоҳи додаҳо.
10. Ҳуҷҷатҳои техникии лоиҳа ва дастури истифода.

## 12. Хулоса

Дар ин ҳуҷҷат талаботи техникӣ ва функсионалии веблоиҳаи маркази таъмири техника муайян карда шуданд. Система барои автоматӣ намудани бақайдгирии муштариён, қабули дастгоҳҳо, ташхис, таъмир, истифодаи қисмҳои эҳтиётӣ, пардохт ва пайгирии ҳолати фармоиш пешбинӣ шудааст.

Технологияҳои PHP ва MySQL барои татбиқи қисми серверӣ ва нигоҳдории маълумот, HTML, CSS ва JavaScript барои сохтани интерфейси веб интихоб шудаанд. Ҳамчунин талаботи амниятӣ, меъёрҳои санҷиш, нақшҳои истифодабарандагон ва марҳилаҳои иҷрои кор муайян карда шуданд.

Ин ҳуҷҷат ҳамчун асос барои татбиқи амалӣ, санҷиш ва қабули веблоиҳаи «Маркази таъмири техника» истифода мешавад.

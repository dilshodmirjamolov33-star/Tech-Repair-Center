# Таҳлили соҳаи мавзуӣ: Веб-системаи маркази таъмири техника «Tech Repair Center»

## 1. Ташкилот

«Tech Repair Center» — веб-системае мебошад, ки барои автоматикунонии фаъолияти маркази ташхис, таъмир ва хизматрасонии техникии таҷҳизоти маишӣ, компютерӣ ва мобилӣ пешбинӣ шудааст. Вазифаи асосии система муттаҳид намудани муштариён, устоҳо ва маъмурияти марказ дар як муҳити ягонаи иттилоотӣ мебошад. Ин муҳит бақайдгирии муроҷиатҳо, коркарди фармоишҳо, назорати марҳилаҳои таъмир ва нигоҳдории таърихи хизматрасониро таъмин мекунад.

Дар доираи соҳаи мавзуӣ фаъолияти маркази хизматрасонӣ баррасӣ мешавад, ки аз муштариён дастгоҳҳои намудҳои гуногунро қабул мекунад: смартфонҳо, планшетҳо, ноутбукҳо, компютерҳои рӯимизӣ, принтерҳо ва техникаи маишӣ. Муштарӣ ҳангоми пайдо шудани нуқсон ба марказ муроҷиат карда, маълумотро дар бораи дастгоҳ пешниҳод мекунад ва мушкилотро шарҳ медиҳад. Пас аз қабули дастгоҳ усто ташхис мегузаронад, сабаби эҳтимолии нуқсонро муайян мекунад, арзиш ва муҳлати иҷрои корҳоро ҳисоб менамояд. Баъди мувофиқа шудани шартҳо бо муштарӣ таъмир анҷом дода шуда, сипас дастгоҳ ба соҳибаш баргардонида мешавад.

То ҷорӣ намудани веб-системаи ягона маълумот дар бораи муштариён, дастгоҳҳо ва фармоишҳо метавонад дар дафтарҳои коғазӣ, ҷадвалҳои электронӣ, паёмрасонҳо ё ҳуҷҷатҳои алоҳида нигоҳ дошта шавад. Дар чунин ҳолат ҷустуҷӯи таърихи муроҷиатҳо душвор мегардад, эҳтимоли гум шудани маълумот зиёд мешавад ва назорати сарбории устоҳо ва сари вақт огоҳ намудани муштариён дар бораи рафти таъмир мушкил мегардад.

Барои ҳалли мушкилоти зикршуда платформаи вебии Tech Repair Center таҳия карда мешавад. Он ба муштариён имконият медиҳад, ки бо хизматрасониҳои марказ шинос шаванд, дархости таъмир фиристанд, намуд ва модели дастгоҳро нишон диҳанд, нуқсонро шарҳ диҳанд ва ҳолати фармоишро пайгирӣ кунанд. Кормандони марказ воситаҳои бақайдгирӣ ва коркарди фармоишҳо, гузаронидани ташхис, таъин намудани устои масъул ва тағйир додани ҳолати таъмирро дастрас мекунанд.

Система қисми кушодаи сомона, утоқҳои шахсии муштариён ва устоҳо, инчунин панели маъмуриро барои идоракунии мутамаркази корбарон, хизматрасониҳо, кормандон ва фармоишҳо дар бар мегирад.

### Мушкилоти раванди мавҷуда

- **Набудани пойгоҳи ягонаи фармоишҳо:** маълумот дар бораи муштариён, дастгоҳҳо ва таъмирҳо метавонад дар дафтарҳо ва файлҳои гуногун нигоҳ дошта шавад. Ин ҷустуҷӯи маълумот ва гирифтани таърихи пурраи хизматрасониро душвор мегардонад.
- **Бақайдгирии дастии муроҷиатҳо:** ҳангоми тартиб додани фармоиш корманд маҷбур мешавад маълумоти тамосии муштарӣ, хусусиятҳои дастгоҳ ва тавсифи нуқсонро дастӣ сабт кунад. Ин вақти қабулро зиёд ва эҳтимоли хатогиҳоро баланд мекунад.
- **Мураккабии назорати марҳилаҳои таъмир:** барои муштарӣ фаҳмидани он ки дастгоҳ қабул шудааст, ташхис анҷом ёфтааст, қисмҳои эҳтиётӣ интизор мешаванд ё таъмир аллакай ба анҷом расидааст, душвор буда метавонад.
- **Ҳамоҳангсозии нокифояи кори устоҳо:** дар сурати набудани тақсимоти мутамаркази фармоишҳо назорати сарбории ҷории кормандон ва масъули иҷрои корҳои мушаххас душвор мешавад.
- **Номуайянии арзиш ва муҳлати иҷро:** то гузаронидани ташхис муштарӣ на ҳамеша дар бораи арзиш ва муҳлати тахминии таъмир маълумоти равшан мегирад. Натиҷаҳои ташхис ва мувофиқаи корҳо бояд дар система сабт карда шаванд.
- **Хатари гум шудани таърихи хизматрасонӣ:** бе системаи ягона барқарор намудани маълумот дар бораи корҳои қаблан иҷрошуда, қисмҳои ивазшуда ва нуқсонҳои пешинаи дастгоҳ душвор аст.
- **Набудани огоҳиномаҳои автоматӣ:** муштарӣ метавонад дар бораи тағйир ёфтани ҳолати фармоиш ё омода шудани дастгоҳ сари вақт паём нагирад.
- **Имкониятҳои маҳдуди таҳлили фаъолият:** маъмурият баҳодиҳии шумораи фармоишҳо, маъруфияти хизматрасониҳо, вақти миёнаи таъмир ва сарбории устоҳоро ба осонӣ анҷом дода наметавонад.

## 2. Иштирокчиён (нақшҳои корбарон)

Дар системаи Tech Repair Center чор намуди асосии иштирокчиён пешбинӣ шудааст. Ҳар як нақш дорои ҳуқуқ ва имкониятҳои функсионалии худ мебошад.

| Нақш дар система | Тавсифи иштирокчӣ | Вазифаҳо ва амалҳои асосӣ |
|---|---|---|
| `admin` | Маъмури маркази хизматрасонӣ | Идоракунии корбарон ва кормандон, илова ва таҳрири хизматрасониҳо, дидани ҳамаи фармоишҳо, таъин кардани устоҳо, назорати ҳолатҳо ва нишондиҳандаҳои асосии фаъолияти марказ |
| `master` | Устои таъмири техника | Дидани фармоишҳои ба ӯ таъиншуда, омӯзиши тавсифи нуқсон, гузаронидани ташхис, нишон додани натиҷаҳо, ҳисоб кардани арзиш ва муҳлат, нав кардани марҳилаҳои иҷрои таъмир |
| `customer` | Муштарии маркази хизматрасонӣ | Бақайдгирӣ, дидани хизматрасониҳо, сохтани дархости таъмир, нишон додани маълумоти дастгоҳ, пайгирии ҳолати фармоиш ва дидани таърихи муроҷиатҳо |
| `guest` | Меҳмон (корбари сабтиномнашуда) | Дидани саҳифаи асосӣ, феҳристи хизматрасониҳо, маълумоти тамос ва маълумоти умумӣ дар бораи марказ; барои сохтани дархост ва пайгирии он ба бақайдгирӣ ё воридшавӣ мегузарад |

**Эзоҳ:** меҳмон ҳолати боздидкунандаи сомона бе иҷозати воридшавӣ мебошад, на нақши алоҳидаи корбари сабтиномшуда. Пас аз ворид шудан ба система корбар мувофиқи нақши худ маҷмӯи ҳуқуқҳои дахлдорро мегирад. Маъмур метавонад ҳисобҳои кормандонро эҷод кунад ё ҳуқуқҳои мувофиқро ба онҳо таъин намояд.

## 3. Равандҳои тиҷоратӣ

Равандҳои асосии тиҷоратии система бақайдгирии корбарон, сохтани дархостҳо, қабули дастгоҳҳо, ташхис, мувофиқаи арзиш, иҷрои таъмир ва супоридани техникаро ба муштарӣ дар бар мегиранд.

| Раванди тиҷоратӣ | Иштирокчиён | Натиҷа |
|---|---|---|
| Бақайдгирӣ ва иҷозати воридшавӣ | `guest`, `customer`, `master`, `admin` | Эҷоди ҳисоби корбар ва додани дастрасӣ ба бахши мувофиқи система |
| Дидани хизматрасониҳо | `guest`, `customer` | Гирифтани маълумот дар бораи намудҳои таъмир, тавсифи хизматрасониҳо ва нархҳои тахминӣ |
| Сохтани дархости таъмир | `customer`, `admin` | Бақайдгирии муроҷиат бо маълумоти тамосии муштарӣ, маълумот дар бораи дастгоҳ ва тавсифи нуқсон |
| Қабули дастгоҳ | `admin`, `master`, `customer` | Сабти ворид шудани дастгоҳ ба маркази хизматрасонӣ ва дар ҳолати зарурат сабти ҳолати зоҳирӣ ва ҷузъҳои он |
| Таъин намудани усто | `admin` | Вогузор кардани фармоиш ба корманди масъул |
| Ташхиси дастгоҳ | `master` | Муайян кардани сабаби эҳтимолии нуқсон, корҳои зарурӣ, қисмҳо, арзиш ва муҳлат |
| Мувофиқаи таъмир | `customer`, `admin`, `master` | Гирифтани розигии муштарӣ ба арзиш ва шартҳои пешниҳодшудаи иҷрои корҳо |
| Иҷрои таъмир | `master` | Иҷрои корҳои мувофиқашуда ва сабти қисмҳои истифодашуда ва натиҷа |
| Назорати ҳолати фармоиш | `customer`, `master`, `admin` | Гирифтани маълумоти ҷорӣ дар бораи марҳилаи таъмир |
| Пардохт ва супоридани дастгоҳ | `customer`, `admin` | Сабти пардохт ва анҷом додани фармоиш пас аз супоридани дастгоҳ ба муштарӣ |
| Назари муштарӣ дар бораи кори иҷрошуда | `customer` | Нигоҳ доштани баҳо ва шарҳи муштарӣ пас аз анҷоми фармоиш |
| Идоракунии фаъолияти марказ | `admin` | Назорати корбарон, кормандон, хизматрасониҳо, фармоишҳо ва омори фаъолият |

### 3.1. Сохтани дархост ва иҷрои таъмир (муфассал)

1. **Ҳодисаи оғозӣ (ангезанда):** муштарӣ сомонаи Tech Repair Center-ро мекушояд, хизматрасониҳои дастрасро мебинад ва қарор мекунад, ки дастгоҳро барои таъмир пешниҳод намояд.

2. **Қадами 1:** муштарӣ дар утоқи шахсӣ сабти ном мекунад ё ба система ворид мешавад. Пас аз воридшавӣ шакли сохтани дархостро мекушояд.

3. **Қадами 2:** муштарӣ навъи дастгоҳ (масалан, смартфон, ноутбук, компютер ё техникаи маишӣ), истеҳсолкунанда, модел, рақами тамос ва тавсифи нуқсонро нишон медиҳад. Агар чунин имконият мавҷуд бошад, ӯ метавонад акси дастгоҳ ё осебро замима кунад.

4. **Қадами 3:** система пур будани майдонҳои ҳатмиро месанҷад ва дархостро дар пойгоҳи додаҳо бо ҳолати `new` (нав) нигоҳ медорад. Муштарӣ рақами фармоишро мегирад, ки барои муайян кардани муроҷиат истифода мешавад.

5. **Қадами 4:** маъмур ё корманди ваколатдор дархости навро мебинад, дар ҳолати зарурат маълумотро дақиқ мекунад ва қабули дастгоҳро сабт менамояд. Фармоиш метавонад ба устои мушаххас таъин карда шавад.

6. **Қадами 5:** усто дастгоҳро аз назар гузаронида, ташхис мегузаронад. Ӯ дар система нуқсонҳои ошкоршуда, корҳои тавсияшаванда, қисмҳои эҳтиётии зарурӣ, арзиши тахминӣ ва муҳлати таъмирро сабт мекунад.

7. **Қадами 6:** система натиҷаҳои ташхисро нигоҳ медорад. Муштарӣ дар бораи ҳолати дастгоҳ, арзиш ва муҳлат маълумот мегирад. Фармоиш ба ҳолати интизории мувофиқа — `waiting_approval` мегузарад.

8. **Қадами 7:** муштарӣ иҷрои корҳои пешниҳодшуда ё рад кардани таъмирро тасдиқ мекунад. Ҳангоми розигӣ фармоиш ҳолати `approved` мегирад ё бевосита ба марҳилаи иҷро мегузарад. Ҳангоми радкунӣ, вобаста ба сабаб ва қоидаҳои марказ, фармоиш ба ҳолати `cancelled` ё `rejected` гузаронида мешавад.

9. **Қадами 8:** усто корҳои таъмири мувофиқашударо иҷро мекунад. Агар қисмҳои зарурӣ мавҷуд набошанд, фармоиш ба ҳолати `waiting_parts` мегузарад. Пас аз гирифтани қисмҳо усто таъмирро идома дода, маълумотро дар бораи рафти иҷро нав мекунад.

10. **Қадами 9:** пас аз анҷоми корҳо усто қобилияти кории дастгоҳро месанҷад ва натиҷаи таъмирро нишон медиҳад. Фармоиш ҳолати `completed` (таъмир анҷом ёфт)-ро мегирад.

11. **Қадами 10:** маъмур ё корманд муштариро дар бораи омода шудани дастгоҳ огоҳ мекунад. Пас аз пардохт ва воқеан ба муштарӣ супоридани техника фармоиш ҳолати `issued` (дастгоҳ супорида шуд)-ро мегирад.

12. **Натиҷа:** маълумот дар бораи дархост, ташхис, устои таъиншуда, корҳои иҷрошуда, пардохт ва тағйироти ҳолат дар пойгоҳи додаҳо нигоҳ дошта мешавад. Муштарӣ метавонад таърихи фармоишро дар утоқи шахсии худ бинад.

#### Ҳолатҳои истисноӣ

- **Маълумоти нодуруст ё нопурра:** агар муштарӣ маълумоти ҳатмиро нишон надиҳад, система дархостро нигоҳ намедорад ва дар бораи зарурати пур кардани майдонҳои дахлдор огоҳӣ медиҳад.
- **Фиристодани такрории дархост:** агар дар натиҷаи чанд маротиба пахш кардани тугма ё нав кардани саҳифа дархост якчанд бор фиристода шавад, система бояд то ҳадди имкон аз сохтани сабтҳои такрорӣ пешгирӣ кунад.
- **Имконнопазирии тамос бо муштарӣ:** агар барои мувофиқаи арзиш ё шартҳои таъмир бо муштарӣ тамос гирифтан имконнопазир бошад, фармоиш дар ҳолати интизорӣ мемонад ва корманд шарҳи дахлдорро сабт мекунад.
- **Рад кардани таъмир аз ҷониби муштарӣ:** агар муштарӣ бо натиҷаҳои ташхис ё арзиш розӣ набошад, таъмир оғоз намешавад. Корманд радкуниро сабт карда, тартиби баргардонидани дастгоҳро мувофиқа мекунад.
- **Набудани қисмҳои эҳтиётӣ:** агар қисмҳои зарурӣ мавҷуд набошанд, фармоиш ба ҳолати `waiting_parts` мегузарад. Муштарӣ дар бораи эҳтимоли таъхир огоҳ карда мешавад.
- **Тағйир ёфтани арзиш:** агар ҳангоми таъмир нуқсони иловагӣ ошкор шавад, усто набояд бе мувофиқа бо муштарӣ корҳои иловагии пулакиро иҷро кунад. Арзиши нав ва сабаби тағйирот дар система сабт карда мешаванд.
- **Иваз шудани устои масъул:** агар устои таъиншуда корро идома дода натавонад, маъмур метавонад корманди дигарро таъин кунад. Тағйирот бояд дар таърихи фармоиш инъикос ёбад.
- **Бекор кардани фармоиш:** бекоркунӣ бо нишон додани сабаб ва бо назардошти корҳои воқеан иҷрошуда ва қоидаҳои марказ анҷом дода мешавад.
- **Ҳамзамон тағйир додани фармоиш:** агар якчанд корманд як фармоишро ҳамзамон кушоянд, система бояд тағйиротро дуруст нигоҳ дорад ва аз гум шудани тасодуфии маълумоти қаблан воридшуда пешгирӣ кунад.
- **Хатои нигоҳдорӣ ё қатъ шудани пайвастшавӣ:** система бояд корбарро дар бораи имконнопазирии анҷом додани амалиёт огоҳ кунад ва тағйироти тасдиқнашударо ҳамчун бомуваффақият нигоҳдошташуда нишон надиҳад.

## 4. Объектҳои маълумот

Объектҳои асосии маълумоти системаи Tech Repair Center мавҷудиятҳоеро дар бар мегиранд, ки барои нигоҳ доштани маълумот дар бораи корбарон, хизматрасониҳо, дастгоҳҳо, дархостҳо ва рафти таъмир заруранд.

| Объект | Маълумоти асосӣ (атрибутҳо) | Робита бо объектҳои дигар |
|---|---|---|
| Корбар (`User`) | Ном, насаб, почтаи электронӣ (ягона), хеши парол, рақами телефон, нақш (`admin`, `master`, `customer`), ҳолати ҳисоб, санаи бақайдгирӣ | Муштарӣ метавонад якчанд фармоиш созад; усто метавонад ба якчанд фармоиш таъин карда шавад |
| Хизматрасонӣ (`Service`) | Ном, тавсиф, категорияи техника, арзиши тахминӣ, муҳлати иҷро (дар сурати мавҷуд будан), ҳолати нашр | Метавонад дар як ё якчанд фармоиш нишон дода шавад |
| Дастгоҳ (`Device`) | Навъи техника, истеҳсолкунанда, модел, рақами силсилавӣ (ҳатмӣ нест), тавсифи ҳолати зоҳирӣ, маълумоти иловагӣ | Ба муштарӣ тааллуқ дорад; метавонад дар давраҳои гуногун якчанд фармоиши таъмир дошта бошад |
| Дархости таъмир (`RepairOrder`) | Рақами фармоиш, идентификатори муштарӣ (`customer_id`), идентификатори дастгоҳ (`device_id`), идентификатори хизматрасонӣ (`service_id`, ҳатмӣ нест), тавсифи нуқсон, санаи эҷод, устои таъиншуда (`master_id`, ҳатмӣ нест), арзиш, муҳлати иҷро, ҳолат | Муштарӣ, дастгоҳ, хизматрасонӣ ва устои таъиншударо бо ҳам мепайвандад; таърихи тағйирот ва амалиётҳои алоқамандро дар бар мегирад |
| Ташхис (`Diagnosis`) | Идентификатори фармоиш (`order_id`), тавсифи нуқсони ошкоршуда, корҳои тавсияшаванда, рӯйхати қисмҳои зарурӣ, арзиши пешакӣ, муҳлати тахминӣ, санаи ташхис, усто | Ба фармоиши мушаххас тааллуқ дорад; метавонад дар рафти хизматрасонӣ дақиқ карда шавад |
| Кори иҷрошуда (`RepairWork`) | Идентификатори фармоиш (`order_id`), номи кор, тавсиф, арзиши кор, қисмҳои истифодашуда, санаи иҷро, иҷрокунанда | Бо фармоиш ва усто алоқаманд аст; барои сабти амалиётҳои воқеан иҷрошуда имкон медиҳад |
| Пардохт (`Payment`) | Идентификатори фармоиш (`order_id`), маблағ, усули пардохт, ҳолати пардохт, сана ва вақти амалиёт, шарҳ | Ба фармоиши мушаххас тааллуқ дорад; агар қоидаҳои марказ иҷозат диҳанд, як фармоиш метавонад як ё якчанд сабти пардохт дошта бошад |
| Таърихи ҳолатҳо (`OrderStatusHistory`) | Идентификатори фармоиш (`order_id`), ҳолати пешина, ҳолати нав, корбаре, ки амалро иҷро кардааст, санаи тағйирот, шарҳ | Бо фармоиши мушаххас алоқаманд буда, пайгирии марҳилаҳои коркарди онро имконпазир мегардонад |
| Огоҳинома (`Notification`) | Идентификатори корбар (`user_id`), сарлавҳа, матни паём, навъи огоҳинома, ҳолати хондашавӣ, санаи эҷод | Ба корбари мушаххас тааллуқ дошта, ӯро дар бораи тағйироти фармоиш огоҳ мекунад |
| Назари муштарӣ (`Review`) | Идентификатори муштарӣ (`customer_id`), идентификатори фармоиш (`order_id`), баҳо, матни шарҳ, санаи эҷод, ҳолати нашр | Бо муштарӣ ва фармоиши анҷомёфта алоқаманд аст; барои баҳодиҳии сифати хизматрасонӣ имкон медиҳад |

**Эзоҳ:** объектҳо ва атрибутҳои овардашуда модели ибтидоии консептуалии соҳаи мавзуиро ташкил медиҳанд. Сохтори ниҳоии ҷадвалҳо, намудҳои майдонҳо, маҳдудиятҳо ва робитаҳо дар марҳилаи тарҳрезии пойгоҳи додаҳои MySQL муайян карда мешаванд.

## 6. Манбаъҳои талабот

Барои муайян кардани талаботи функсионалӣ ва иттилоотии система истифодаи усулҳои зерини омӯзиши соҳаи мавзуӣ пешбинӣ мешавад.

### Усули 1. Мусоҳиба

Барои дақиқ намудани талабот ба системаи оянда гузаронидани мусоҳиба бо соҳиби маркази хизматрасонӣ, маъмурон, устоҳо ва муштариёни эҳтимолӣ пешбинӣ мешавад.

Саволҳои асосӣ барои мусоҳиба:

1. Марказ кадом намудҳои техникаро қабул мекунад?
2. Кадом хизматрасониҳои ташхис, таъмир ва нигоҳдорӣ пешниҳод карда мешаванд?
3. Ҳангоми сохтани фармоиш кадом маълумот дар бораи муштарӣ ва дастгоҳ бояд сабт карда шавад?
4. Дастгоҳҳоро кӣ барои таъмир ба қайд мегирад — худи муштарӣ ё корманди марказ?
5. Фармоишҳо байни устоҳо чӣ гуна тақсим карда мешаванд?
6. Кадом марҳилаҳои таъмир бояд ба муштарӣ нишон дода шаванд?
7. Оё усто бояд натиҷаи ташхис, арзиш ва муҳлати тахминиро нишон диҳад?
8. Муштарӣ розигии худро ба таъмир ва арзиши пешниҳодшуда чӣ гуна тасдиқ мекунад?
9. Набудани қисмҳои эҳтиётӣ ва таъхири иҷрои корҳо чӣ гуна сабт карда мешаванд?
10. Дар марказ кадом усулҳои пардохт истифода мешаванд?
11. Муштариён ва кормандон бояд кадом огоҳиномаҳоро гиранд?
12. Ба маъмурият кадом ҳисоботҳо ва нишондиҳандаҳои оморӣ заруранд?

### Усули 2. Таҳлили ҳуҷҷатҳо

Барои муайян кардани сохтори маълумот ва қоидаҳои тиҷоратии система омӯзиши маводи зерин пешбинӣ мешавад:

- Шаклҳои қабули техника барои таъмир ва намунаҳои расидҳо.
- Дафтарҳои бақайдгирии муштариён ва дастгоҳҳои қабулшуда.
- Рӯйхати хизматрасониҳо ва нархномаҳои марказ.
- Намунаҳои хулосаҳои ташхисӣ.
- Қоидаҳои мувофиқаи арзиш ва муҳлати таъмир.
- Ҳуҷҷатҳое, ки корҳои иҷрошуда ва қисмҳои эҳтиётии истифодашударо сабт мекунанд.
- Қоидаҳои пардохт, супоридан ва баргардонидани дастгоҳҳо.
- Шартҳои кафолат ба корҳои иҷрошуда ва қисмҳои насбшуда.
- Қоидаҳои дохилии тақсим намудани фармоишҳо байни устоҳо.

### Усули 3. Мушоҳидаи раванд

Омӯзиши раванди маъмулии хизматрасонии дастгоҳ — аз муроҷиати аввалини муштарӣ то супоридани техникаи таъмиршуда — пешбинӣ мешавад.

Дар доираи мушоҳида ҳолатҳои зерин бояд баррасӣ карда шаванд:

- Қабули муроҷиати муштарӣ ва бақайдгирии маълумот дар бораи дастгоҳ.
- Азназаргузаронии аввалияи техника ва сабти ҳолати зоҳирии он.
- Таъин намудани устои масъул.
- Гузаронидани ташхис ва омода кардани хулоса.
- Мувофиқаи арзиш ва муҳлати иҷро бо муштарӣ.
- Иҷрои таъмир, истифодаи қисмҳои эҳтиётӣ ва санҷиши натиҷа.
- Тағйир додани ҳолати фармоиш ва огоҳ намудани муштарӣ.
- Пардохти хизматрасониҳо ва супоридани дастгоҳ.
- Нигоҳ доштани таърихи хизматрасонӣ ва гирифтани фикру мулоҳизаи муштарӣ.

Натиҷаҳои таҳқиқот имкон медиҳанд, ки мушкилоти асосии раванди мавҷуда муайян гардида, талаботи функсионалӣ ва иттилоотӣ ба веб-системаи таҳияшавандаи Tech Repair Center ташаккул дода шаванд.

## 7. Маҳдудиятҳои пешакии технологӣ

Системаи таҳияшаванда барои истифодаи технологияҳои зерин пешбинӣ шудааст:

| Ҷузъи система | Технологияи пешбинишуда | Вазифа |
|---|---|---|
| Қисми серверӣ | PHP | Коркарди дархостҳо, мантиқи тиҷоратӣ, иҷозати воридшавӣ ва идоракунии маълумот |
| Пойгоҳи додаҳо | MySQL | Нигоҳ доштани маълумот дар бораи корбарон, хизматрасониҳо, дастгоҳҳо, фармоишҳо ва таърихи таъмир |
| Қисми муштарӣ | HTML5, CSS3, JavaScript | Ташаккули интерфейс ва унсурҳои интерактивӣ |
| Сервери веб барои таҳияи маҳаллӣ | Apache (XAMPP) | Иҷрои барномаи PHP дар муҳити маҳаллӣ |
| Муҳити таҳия | Visual Studio Code | Эҷод, таҳрир ва ислоҳи файлҳои лоиҳа |
| Назорати версияҳо | Git ва GitHub | Нигоҳ доштани коди ибтидоӣ ва пайгирии тағйироти лоиҳа |

Маҷмӯи технологияҳои зикршуда пешакӣ муайян гардида, метавонад дар ҷараёни тарҳрезӣ дақиқ карда шавад. Меъмории барнома бояд ҷудо будани интерфейс, мантиқи серверӣ, танзимоти пайвастшавӣ ба пойгоҳи додаҳо ва модулҳои алоҳидаи функсионалиро таъмин намояд.

## Хулоса

Дар натиҷаи таҳлили соҳаи мавзуӣ иштирокчиёни асосии системаи Tech Repair Center, имкониятҳои функсионалии онҳо, равандҳои тиҷоратӣ, объектҳои иттилоотӣ ва истилоҳоти калидӣ муайян карда шуданд.

Платформаи вебии таҳияшаванда имкон медиҳад, ки маълумот дар бораи муштариён ва дастгоҳҳо мутамарказ карда шавад, бақайдгирӣ ва коркарди дархостҳо автоматӣ гардад, тақсим намудани фармоишҳо байни устоҳо осон шавад, марҳилаҳои таъмир назорат карда шаванд ва шаффофияти ҳамкорӣ бо муштариён баланд бардошта шавад.

Натиҷаҳои бадастомада барои таҳияи супориши техникӣ, моделсозии диаграммаҳои UML, тарҳрезии пойгоҳи додаҳои MySQL ва татбиқи минбаъдаи веб-барнома дар PHP замина мегузоранд.

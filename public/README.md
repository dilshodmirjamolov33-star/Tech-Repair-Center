# Tech Repair Center — сохтори мутобиқшуда

Сохтори файлҳо ба намунаи `public/` мутобиқ карда шудааст. Логикаи мавҷудаи PHP нигоҳ дошта шудааст.

- `config.php`, `database.sql`, `setup.php` дар реша
- саҳифаҳои PHP дар `public/`
- CSS ва JS дар `public/assets/css` ва `public/assets/js`
- `api/availability` — API-и пайгирии квитансия
- `api/fields` — API-и рӯйхати фармоишҳо барои корманди воридшуда
- `static/` — саҳифаҳои иттилоотӣ

**Муҳим:** ин сохтор аз нав ҷойгиркунии файлҳо ва API-и намунавӣ мебошад; пеш аз deploy, конфигуратсияи сервер бояд document root-ро ба `public/` равона кунад. Маълумоти DB дар `config.php` барои муҳити маҳаллӣ ҳоло ҳам ҳамон аст.

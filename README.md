# Tech Repair Center

**Веблоиҳаи маркази таъмири техника**

## Маълумот дар бораи лоиҳа

Tech Repair Center — системаи вебӣ барои автоматизатсияи фаъолияти маркази таъмири техника мебошад. Система барои қабул ва бақайдгирии дархостҳои таъмир, идоракунии фармоишҳо, ташхиси дастгоҳҳо ва назорати раванди таъмир пешбинӣ шудааст.

Мақсади асосии лоиҳа осон намудани фаъолияти маркази таъмири техника ва беҳтар намудани хизматрасонӣ ба мизоҷон мебошад.

## Мақсадҳои лоиҳа

- Автоматизатсияи раванди қабули техника барои таъмир.
- Бақайдгирии мизоҷон ва кормандон.
- Идоракунии дархостҳо ва фармоишҳои таъмир.
- Назорати ҳолати таъмири дастгоҳҳо.
- Таъини усто ба фармоишҳо.
- Нигоҳдории маълумот дар пойгоҳи додаҳо.
- Таъмини дастрасии мизоҷон ба таърихи таъмир.

## Нақшҳои истифодабарандагон

Система чор гурӯҳи истифодабаранда дорад:

1. **Guest (Меҳмон)** — дидани хизматрасониҳо ва бақайдгирӣ.
2. **Customer (Мизоҷ)** — фиристодани дархост, дидани ҳолати таъмир ва таърихи фармоишҳо.
3. **Master (Усто)** — ташхиси техника, сабти натиҷаи таъмир ва тағйир додани ҳолати фармоиш.
4. **Admin (Маъмур)** — идоракунии мизоҷон, устоҳо, хизматрасониҳо ва фармоишҳо.

## Имкониятҳои асосии система

- Бақайдгирӣ ва воридшавӣ ба система.
- Каталоги хизматрасониҳои марказ.
- Қабули дархостҳои таъмири техника.
- Идоракунии фармоишҳо.
- Ташхиси дастгоҳҳо.
- Ҳисоб кардани арзиши таъмир.
- Назорати ҳолати иҷрои фармоиш.
- Идоракунии истифодабарандагон.
- Ҳисобгирии қисмҳои эҳтиётӣ.
- Ҳисобгирии пардохтҳо.

## Талаботи система

Барои ба кор даровардани лоиҳа зарур аст:

- Windows 10 ё Windows 11.
- PHP 8.2 ё версияи навтар.
- MySQL ё MariaDB.
- XAMPP.
- Visual Studio Code.
- Браузери муосир.

## Насб ва ба кор даровардани лоиҳа

**Қадами 1.** Репозиториро ба компютер нусхабардорӣ кунед:

```bash
git clone https://github.com/USERNAME/tech-repair-center.git
```

**Қадами 2.** Ба папкаи лоиҳа гузаред:

```bash
cd tech-repair-center
```

**Қадами 3.** Лоиҳаро дар Visual Studio Code кушоед:

```bash
code .
```

**Қадами 4.** Apache ва MySQL-ро дар XAMPP фаъол кунед.

**Қадами 5.** Пойгоҳи додаҳоро тавассути phpMyAdmin созед.

**Қадами 6.** Танзимоти пайвастшавӣ ба MySQL-ро дар файли конфигуратсияи лоиҳа ворид кунед.

**Қадами 7.** Лоиҳаро тавассути браузер кушоед.

```text
http://localhost/tech-repair-center/
```
